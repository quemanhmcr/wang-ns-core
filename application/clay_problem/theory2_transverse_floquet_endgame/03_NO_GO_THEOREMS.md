# 03 — No-go theorems

This file records only rigorous obstructions to proposed closure mechanisms. Each theorem states that a certain implication does **not** follow from the current axioms.

## Theorem 1 — Direct-product radial absorption

Let \(E\) be any finite family of companion edges and let

\[
F_e=\kappa\mathscr R_{\sigma_e}f_e.
\]

Define

\[
\mathbf R_E:=\bigoplus_{e\in E}\kappa\mathscr R_{\sigma_e},
\qquad
\mathbf S_E:=\bigoplus_{e\in E}\mathcal S_{\sigma_e}.
\]

Then

\[
\boxed{\mathbf R_E\mathbf S_E=I.}
\]

Hence every finite admissible forcing family has the unique edgewise absorber

\[
\boxed{f_e=\mathcal S_{\sigma_e}F_e.}
\]

### Consequence

The radial equations themselves impose **no compatibility equation between distinct edges**. Reality completion only adds the corresponding conjugate solutions.

## Theorem 2 — Rank-one holonomy is exactly flat

For a finite bipartite incidence graph with

\[
Z_{ij}=A_iB_j\neq0,
\]

every multiplicative identity valid for arbitrary factors is generated by alternating cycles. For

\[
\Gamma:i_1-j_1-i_2-j_2-\cdots-i_m-j_m-i_1,
\]

define

\[
\operatorname{Hol}^Z_\Gamma
:=
\prod_{\ell=1}^m
\frac{Z_{i_\ell j_\ell}}{Z_{i_{\ell+1}j_\ell}},
\qquad i_{m+1}=i_1.
\]

Then

\[
\boxed{\operatorname{Hol}^Z_\Gamma=1.}
\]

Thus the only holonomy supplied by rank one alone is tautologically flat.

## Theorem 3 — Rank one plus radial absorption does not produce a nontrivial holonomy defect

Write

\[
F_e=Z_e\Phi_e.
\]

By linearity of the radial inverse,

\[
\boxed{f_e=Z_eG_e,\qquad G_e:=\mathcal S_{\sigma_e}\Phi_e.}
\]

Rank one constrains the scalars \(Z_e\). It imposes no relation among the state-shape vectors \(G_e\), which generally lie in different Fourier/helicity/radial output fibers.

Therefore there is no canonical identity such as

\[
G_{ii}G_{jj}=G_{ij}G_{ji}.
\]

Indeed that expression is not intrinsically defined without a projective identification of the different output fibers.

Hence

\[
\boxed{
\text{rank one + reality + exact radial absorption}
\not\Longrightarrow
\text{nontrivial scalar loop defect}.
}
\]

More generally, if a scalar functional \(\mathcal H\) is claimed to satisfy

\[
\text{simultaneous exact absorption}\Longrightarrow \mathcal H=1
\]

using only the displayed edgewise equations, then Theorem 1 forces \(\mathcal H=1\) on the entire locally admissible forcing class. Such an \(\mathcal H\) cannot also satisfy

\[
|\mathcal H-1|\ge c>0.
\]

## Theorem 4 — Finite Poisson/heat readers are not injective on the natural radial packet space

Fix an annulus \(I\Subset(0,\infty)\) and let

\[
X=C_c^\infty(I).
\]

Take any finite family of Poisson/heat depth readers, together with any finite family of the same type applied to \(\mathscr R_\sigma f\). Then there exists

\[
0\neq g_0\in X
\]

annihilated by all readers.

### Proof

Every chosen measurement is a linear functional on the infinite-dimensional space \(X\). A finite intersection of their kernels is nontrivial. Choose \(g_0\) there and any nonzero angular profile \(\phi(\omega)\); set

\[
g(\rho,\omega)=g_0(\rho)\phi(\omega).
\]

All retained angular outputs vanish because their radial coefficients vanish. Also \(\mathscr R_\sigma g\neq0\): otherwise \(g_0\) would be a compactly supported homogeneous solution, impossible by the classification in `02_STATIONARY_FINITE_VISCOSITY.md`. ∎

Thus a nonzero exactly absorbable packet can be invisible to every selected finite reader.

## Corollary 5 — Compactness does not imply finite-depth injectivity

Let \(L\) be any fixed finite reader and choose \(0\neq g\in\ker L\). Then for arbitrary \(f_0\),

\[
K_0:=\{f_0+tg:0\le t\le1\}
\]

is compact but

\[
L(f_0+tg)=L(f_0)
\]

for every \(t\).

Hence

\[
\boxed{
\text{compactness}\not\Longrightarrow\text{finite-reader injectivity}.
}
\]

The Vandermonde argument remains valid only on an independently proved finite-dimensional jet/profile class.

## Theorem 6 — Additive mixing obstructs ordinary edgewise holonomy

Suppose two physical interactions \(e_1,e_2\) feed the same occupied output packet \(r\). Even if their absorbed contributions lie in the same one-dimensional state line,

\[
\mathcal S_rF_{e_1}=c_1\psi_r,
\qquad
\mathcal S_rF_{e_2}=c_2\psi_r,
\]

the physical output is

\[
(c_1+c_2)\psi_r.
\]

If each channel coefficient is written schematically as

\[
c_e=h_ea_{p_e}a_{q_e},
\]

then the actual state amplitude satisfies

\[
\boxed{
a_r=\sum_{e:r_e=r}h_ea_{p_e}a_{q_e},}
\]

not the edgewise law

\[
a_r=h_ea_pa_q.
\]

Therefore an ordinary multiplicative connection can only be defined **before physical channel summation**, with explicit channel resolution. This is not supplied by the present Theory-2 axioms.

## Theorem 7 — Compactness cannot extract an exact finite completed witness

An infinite physical ancestry may form an increasing chain

\[
\Gamma_1\subset\Gamma_2\subset\Gamma_3\subset\cdots
\]

in which every finite stage has open companion outputs feeding the next stage. Compactness may yield convergent packet parameters or approximate recurrence, but

\[
\boxed{
\text{approximate recurrence}\not\Longrightarrow\text{exact algebraic completion}.
}
\]

Hence

\[
\boxed{
\text{compactness + finite-network rigidity}
\not\Longrightarrow
\text{PDE rigidity}
}
\]

without a separate finite-witness extraction theorem.

## Theorem 8 — Angle compactness requires nonvanishing \(T\)

Exclusion of positive proportionality

\[
T(v)\neq\lambda R_{\rm fv}(v),\qquad \lambda>0,
\]

on a compact class does not by itself imply a uniform angle gap if \(T\) may approach zero.

However this defect does **not** affect the normalized saturation ratio

\[
\Psi(v)=
\frac{\|T-\kappa R_{\rm fv}\|}
{\|T\|+\kappa\|R_{\rm fv}\|},
\]

because \(R_{\rm fv}\neq0\) on the normalized class.
